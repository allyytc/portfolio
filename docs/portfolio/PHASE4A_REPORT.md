## Lighting implementation and validation

`bake_export_phase4a.py` uses Cycles, 96 samples, a 2048² atlas, 12px bleed and a separate non-overlapping `LightBakeUV`. It bakes diffuse COLOR + DIRECT + INDIRECT for the static furniture/floor/foliage group. Original source UVs are named `SurfaceUV` and explicitly connected to material textures. The moving paper is hidden during baking, preventing its shadow from being stuck in the static map. Final bake took 67.51 seconds on this host.

The static export uses **`KHR_materials_unlit`**, with the baked atlas as base color. Three disables its shadow casting/receiving, so browser lights do not illuminate it again. Blender's camera-ray emission/transparent material graph prevents the baked surface from becoming a new area emitter in the preview. The exported extension and texture reference were inspected in the GLB JSON; see `gltf-verification.json`.

Monitor, sign, printer and paper remain independent PBR nodes under the existing raycasting and paper-animation contract. Blender and Three now use AgX at neutral exposure. No bloom or new animation framework. Existing realtime shadows are restricted to the PBR targets; the single contact-shadow pass provides grounding beneath the plinth.

**Parity check:** the baked desk, floor, chair, plant and rug now retain the same color/shadow structure in Blender and Chrome. PBR lighting is still approximate: the browser sign is darker/more saturated and cream printer/monitor tones differ slightly from Blender's area-light render. This is visible in the comparison, not claimed solved. The two screenshots also use different orthographic framing. A later lighting calibration pass should address the dynamic targets without rebaking or double-lighting the static atlas.

## Comparison with the approved clean loft concept

The reference is the owner-supplied image in the conversation; no unverified external image URL or substitute concept was introduced. The evidence above compares actual before/after captures; this paragraph compares them visually with that reference.

- **Still below target:** the reference has more sophisticated rounded furniture, richer material microdetail, softer textiles, dense trailing foliage and finished architecture. Baked diffuse surfaces do not reproduce view-dependent metallic/specular highlights. The source UV/grain direction is not yet individually art-directed on every board.
